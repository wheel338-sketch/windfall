# Original E3 examples

These six parameter examples were authored for Windfall on 2026-10-11 and
are dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
They contain no audio, proprietary presets, samples, impulse responses or
vendor code. The Windfall implementation remains under its repository licence.

Apply the JSON as `SetEffectParams` after adding its effect kind, or enter the
values in that effect's editor. Omitted settings use the processor's defaults.
Bucket mode I chooses a different clocked circuit; four phaser stages at zero
stagger choose the pedal circuit. Voice/order counts select real processing.
The space example mixes a feed-forward octave into a modulated hall.

Acceptance is written, not executed; see `project/tests/e3_circuits.rs` and the
E3 handoff for integrator commands.
