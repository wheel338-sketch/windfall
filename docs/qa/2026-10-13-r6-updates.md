## What changed and what is implemented

`apps/desktop/src-tauri/src/session/{update_shutdown,preparation,files,audio}.rs`:

- Update preparation bounds the wait for existing save/native-capture exclusion
  to five seconds, then freezes admission. An already-prepared capture cannot
  publish across the freeze; a fresh full native capture includes unpublished
  state, including a plugin edit that has not reached the Document.
- Open native editors and their exact native parent handles are retained, then
  closed on their owners before capture. Capture is bounded and returns a
  visible refusal through the existing update section if the owner/helper does
  not answer. No unsaved snapshot or installation is admitted on that failure.
- Changed state/parameters are published through one checked command batch,
  preserving dirtiness and Undo/Redo. Native capability changes use the existing
  readmission command. The unsaved prompt receives this actual native snapshot.
- Preparation now completes the owned quiesce before returning the decision:
  monitoring stops, the device closes/joins its callback, and hosted owners are
  joined. Installation's `quiesce` remains idempotent. Save serializes the frozen
  document without trying to capture a stopped processor or accepting later
  native changes.
- Rollback reapplies the retained opaque bytes to a detached, prepared engine
  plan before reopening audio, preserves accepted Save/path changes, restores
  monitoring, and reopens each previously open editor with its original parent.
  The freeze remains held through restoration. Recovery failures are returned
  explicitly. Audition note-on cannot enter the installation freeze.

`apps/desktop/src-tauri/src/plugins/{runtime,bridge}.rs`,
`crates/windfall-plugin-host/src/bridge/{helper,supervisor}.rs`, and
`crates/windfall-engine/src/{device,project_preparation}.rs`:

- Both in-process and helper records retain transient editor parent ownership.
  Update requests have a bounded plain-data cancellation path; ordinary native
  requests retain their previous joined recovery semantics.
- Completed unpublished native capture/readmission state can be consumed by the
  update freeze rather than discarded or requested from an unavailable adapter.
  A stale selected native binding/revision refuses the decision.
- Native instrument retirement delivers all-notes-off and reset on its owner.
  Helper shutdown releases notes and deactivates on its native/GUI owner, then
  confirms helper exit. Owner idle retirement and the explicit update barrier
  share that joined path, including the race where idle sees retirement first.
- Fresh native/helper processors clear transient sounding voices after restoring
  their settings/opaque state. Held live notes are not reconstructed. The shared
  stream close/reopen protocol preserves sequenced resume intent; a user Stop
  while detached revokes it. Native fixtures use that production protocol.

`crates/windfall-project/src/lower.rs` supports the same checked readmission for
nested hosted rack nodes, retaining atomic refusal, persistence and history.

`apps/desktop/src-tauri/src/{updates,update_transfer}.rs` expands
`{{current_version}}`, `{{target}}`, `{{arch}}` and `{{bundle_type}}` before the
streaming manifest fetch, including Tauri's encoded template form and encoded
version build metadata. Platform/architecture come from the pinned updater's
native target; bundle type comes from the installed bundle. Unknown/malformed
placeholders are refused. The expanded URL is limited to 8192 bytes and requires
HTTPS, except literal loopback HTTP; credentials are refused. Loopback fetches
bypass proxies. Redirects remain bounded, credential-free and HTTPS-only.
