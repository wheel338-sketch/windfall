`apps/desktop/src-tauri/src/session/tests/files_qa.rs`.

Archive extraction writes a durable ownership marker and acquires an exclusive
OS file lock before extracting payload bytes. The lock transfers to the
session after checked installation. The marker distinguishes partial requests,
installed projects, immutable capture copies and saved-project references.
Save, numbered save and backup journal actual extraction references before
publication. Recovery checks the saved files themselves, so failed publication
does not create a permanent reference. Unreadable references preserve audio.
No IO occurs under the document mutex during collection.

A sampler IPC capture now owns an immutable audio copy and a bounded-operation
lease while taking it. Replacing its source project can reclaim that project's
extraction, while the same capture remains reusable. Graceful session end
collects unused capture copies immediately; restart collects copies abandoned
by process death. A live owner is never swept. Saved references retain their
exact bytes across sessions. Complete unsaved extractions move intact to
`recovered-projects` and enter the real Recent projects list. An initial native
checkpoint precedes installation; final-owner shutdown checkpoints subsequent
document edits. Partial extraction recovery deletes only the request's marked
root. Unmarked legacy/user directories and damaged journals are preserved.
