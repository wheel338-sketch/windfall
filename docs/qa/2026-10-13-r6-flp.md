## What changed for fmt-flp-import

`crates/windfall-flp/src/convert/native.rs` enumerates every active DawVert
native definition intersecting the existing stand-in tables, plus the public
commented Effector and unfinished Multiband Delay/Pitch Shifter prefixes.
Variable Vocoder/Waveshaper records, SSLF framing, short-version variants and
all named tails are bounded and decoded. Known states no longer silently use
stand-in defaults: mapped values print their source field, rule and descriptor
ID; every decoded field without an equivalent target control is named. Invalid
length/range/nonfinite input receives a device-specific safe-default warning.
Original blobs still persist. `convert/effects.rs`, `mixer.rs`, `synth.rs` and
`voice.rs` use the established conversion/descriptor patterns.

DX10 includes public power ADSRs, operator coarse/fine ratios, branch enable,
carrier octave and vibrato/LFO fit. Plucked/BooBass/Fruit Kick/Granulizer and
BassDrum have native translations. SimSynth cutoff/Q, independent filter ADSR
and LFO and weighted shared oscillator pitch routes are translated; every
public float/flag is reported. Per-oscillator topology and target descriptor
limits are identified explicitly. No acoustic equivalence is asserted.

`convert/slices.rs` decodes Slicer custom keys/names/reverse/frame positions,
Slicex filename/embedded WAV and cue frames, and BassDrum's filename. Desktop
`session/flp.rs` resolves actual decoded audio: sparse slice maps, external WAV
cues/labels, inverse-peak normalization, silence threshold/window, and Layer Kick
PCM. Embedded Slicex PCM8/16/24/32/float32 uses an original bounded RIFF reader,
mono fallback and a 4,194,304-frame limit; Layer Kick uses its existing int16,
32,768-frame, faded-truncation asset. External references and original native
bytes remain recoverable. Missing/unsupported/budget-exceeding audio is warned.
Granulizer's event-196 reference is attached to its sample playback asset.

Parameter links use explicit named source dataset `num` and target descriptor
IDs, preserving append-only saved addresses. Clip curves and recorded event 223
use the same numerical functions. The latter recognizes public normalized f32
bit words, including plugin zero endpoints, while accepting legacy small native
integer words. Every unmapped instrument target names the device and parameter
for both recorded events and automation clips; no byte offset is used as a number.
Free Filter's dataset/converter disagreement is reported: explicit dataset
numbering with the converter's type/700 and freq/1024 ranges supplies seven named
responses; ambiguous zero type safely chooses lowpass. Synthetic response tests
assert the actual append-only choice order.

`model.rs`, `parse.rs`, `plugin.rs` and channel conversion map signed keyboard
fine tune, main-pitch participation, inclusive playable range, add-root key
transposition, rack group names, wrapper MIDI bend range/send flag, modern and
legacy cutoff/Q controls, sample offset/crossfade, normalization, trim and
DC/swap/polarity private effects. **Event 83 is resonance**, independently agreed
by PyFLP/DawVert/LMMS; its existing fixture now asserts this correction. Pitch
range is wrapper MIDI record1 bytes8..12, not event83 or a guessed event219 tail.
Known shift/gate/LFO anchors and full-portamento gate bypass are translated.

`convert/patterns.rs` saves source note-edit groups independently of MIDI color.
Project fields default empty on older files. `SetNoteEditGroups` is appended to
Command; lowering validates members/counts, Edit/patch/history carry changes,
and dead IDs are inert after ordinary note deletion. Editor grouped selection
feeds normal move/resize commands. Both sampler and instrument slides choose the
highest same-color sounding pitch at onset, including an ongoing glide; slide
onset/end and original note endings are retained without allocation on callback.

`convert/timeline.rs` keeps Start and paired Punch regions, positive song-loop
extents limited to the active arrangement, suppressed-pause labels, and explicit
unpaired/empty-region warnings. Project/engine timeline compilation distinguishes
recording/start annotations from navigation. Default song play honors Start;
explicit seeks/selected ranges win. Desktop recording uses the paired Punch
interval through its existing bounded recording clock/region path and restores
the previous region after capture. Existing timeline UI edits the persisted
markers. All changes are owned by this row; the legacy preset importer, parity
files, generated bindings and generated simulator artifacts were not touched.

## Source scope and remaining work

SOFTWARE: No identified unimplemented public semantic layout/numbering within
the requested existing stand-in set is knowingly left at generic defaults.
This is an implementation hand-off, **not row acceptance**: all new code still
needs compile/test/strict-gate validation by the build-capable integrator.

SCOPE: Instrument numbering cannot be derived from state offsets. Decoded
3x Osc/DX10/Plucked/BooBass/Fruit Kick/SimSynth/Slicer/Granulizer/BassDrum dataset
entries lack named automation `num`; Sytrus/Harmless entries are anonymous
param_N ranges without meanings or native state layouts. PyFLP plugin parsers
and LMMS add no semantic number-to-knob map. Per-target warnings and retained
source events implement the requested lawful fallback.

SCOPE: Controller source/location/flags/smoothing offsets are known, but DawVert
`auto.py` neither reads nor writes its initialized formula string and supplies
no smoothing time conversion. PyFLP controller source/trailing fields are
unnamed; MIDI event226 is GreedyBytes; LMMS supplies no extra serialization/units.
Non-clip/MIDI links therefore report source hex, target, flags and raw smoothing
per link; no fabricated formula bytes or milliseconds are executed.

SCOPE: PyFLP publishes shift0/1024, gate450/1446/1447 and the LFO32950 anchor,
not nonlinear interior equations. DawVert stores raw words and its LFO
conversion is commented out; LMMS logs these values. Anchors are implemented,
every other nonzero value has a source-evidence warning. MIDI-through/declick/
legacy-trim/drum-stretch flags/floats are decoded, but the checked sources do not
establish the required routing operation, kernel or physical units; each is
named. Formant offset is decoded; the target only exposes preserve-formants.

SCOPE: Native devices lacking public state layouts are named individually in
reports (definitions, DawVert decoder/converters, PyFLP parsers and LMMS checked).
Slicex state beyond the public WAV payload, unknown SSLF/raw sections and
unfinished-definition tails have no public semantic schema. Effector's only
candidate is a commented typed prefix; it is decoded, with named limits on
selector/modulation semantics. Capability limits of the selected stand-ins are
reported separately from format absence. State retention is never represented
as acoustic equivalence or as execution by an unrelated host.
