# Second pass — piano roll and event editing

Branch `gpt/p2-piano`, base `038a7de0970be077857db15a32a54a2cb82b8f74`.
Implementation hand-off; every new test is **written, not executed**.
The worker brief prohibits builds, generators, tests and sub-agents.

## Seams

- MIDI capture owner supplies `Pattern.noteCurves` and note expression using
  the existing note/curve commands. Piano rendering/editing reads that canonical
  data; no parallel frontend capture model.
- `midi:note` must report accepted sounding down/up transitions, with deferred
  up for sustain and releases on panic/disconnection/destination replacement.
  Chord state keeps hardware ownership separate from audition ownership.
- Bridge worker owns helper-provider expression negotiation and recovery.
  This branch owns desktop native expression mapping and engine-facing transport.

## Progress

`wf-chord-detection`: native note feed now joins the held-key store. Repeated
down is idempotent, receiving channels filter the readout, audition releases
do not clear hardware keys, and replacement/disconnect clear both sources.
Tests and remaining rows will be recorded with each implementation commit.

No parity status files or generated artifacts are edited.

## Pattern event editor and consumers

`win-event-editor`: snap chooser, live pattern/song-local SVG playhead, queued
edit project-generation/unmount guards; native/WASM mounted edit/history/file
and race cases. Frontend automation lookup now resolves event-lane IDs and
opens the correct pattern from a driven control. Browser realtime mirrors
pattern events in pattern and song modes. Playlist pattern previews include
bounded event silhouettes, and hold overviews compile offset/repeated events
with ordinary clip priority. FLP event 223 now imports supported channel/mixer
volume/pan, send and effect-mix controls through `SetPatternEvents`; unsupported
plugin raw encodings and pattern tempo remain explicit import losses.

Tests **written, not executed**: `event-editor/panel.qa.test.tsx` (2 mounted
cases), `lanes.test.ts::joins repeated pattern events to playlist priority,
offsets and end holds`, `preview.test.ts::shows event-only patterns as bounded
silhouettes at their real source ticks`, `conversion.rs::recorded_pattern_controls_import_from_real_bytes_as_held_lanes`.
Integrator: `cargo test -p windfall-flp --test conversion`; regenerate WASM;
`pnpm --dir apps/desktop test --maxWorkers=4 panel.qa lanes.test preview.test`.
