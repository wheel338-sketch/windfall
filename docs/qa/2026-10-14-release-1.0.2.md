# Windfall 1.0.2: SoundFonts for agents and users, silent-channel warnings — 2026-10-14

A follow-up to 1.0.1. A user making a song with Claude through the MCP server
found a "Choir" channel (a SoundFont player with no SoundFont) silent the
whole song with no warning, and no way for an agent to load a SoundFont
preset. 1.0.2 fixes both, for agents (MCP) and in the app.

- Worktree `.claude/worktrees/r102`, branch `feat/1.0.2`, from `95b76bba`
  (1.0.1 plus the Linux/macOS portability fixes). Nothing pushed, tagged or
  published.
- One build or test process at a time through `target/r102/run.sh`
  (`CARGO_BUILD_JOBS=8`, Vitest `--maxWorkers=4`); logs
  `target/r102-<step>.log`. No sub-agents.
- Every app launched ran on the software sink (`WINDFALL_SOFTWARE_AUDIO=1`)
  with its own `WINDFALL_CONFIG_DIR` and `WEBVIEW2_USER_DATA_FOLDER`. The
  installed Windfall and its profile were not touched.

## 1. What was built

### For agents (MCP), 31 → 36 tools

| Item | What |
|---|---|
| A1 `list_soundfont_presets {path, search?, offset?, limit?}` | Read tool. Bank, program, name, General MIDI family (bank 0 by program, bank 128 "Drum Kits") and GM program name. Read by Windfall (`Session::soundfont_presets`). |
| A1 `load_soundfont_preset {channelId, path, bank?, program, replaceInstrument?}` | Edit tool, a normal proposal. A channel that is not a SoundFont player is refused with a clear message unless `replaceInstrument: true`, which switches the built-in instrument to a SoundFont player in the same undo step (the MIDI-output "Use GM preset" switch, `ApplyPluginPreset`), keeping notes, mixer track and name. Samplers and hosted plugins are refused. |
| A1 file rule | Every path an agent names goes through `Host::library_file` → `library::confined_file`: absolute paths only; any `.` or `..` segment refused outright; the file must be inside one of the browser's roots (factory content first, then `settings.browserRoots`); no symbolic link or junction anywhere between the root and the file; the canonical file must lie inside the canonical root; it must be a regular file. Checked when the proposal is filed and again when it is applied (a root removed in between makes the apply fail). |
| A1 proposal shape | The proposal registry is unchanged: raw `RegisterSoundFontSource` and `SetSampleInstrumentAsset` are still refused. A proposal now carries an optional `NativeEdit` (SoundFont load or channel preset) beside its allowlisted commands; `Host::apply_native` builds the load commands itself (`windfall_project::sample_instrument::soundfont_load_commands`, shared by the preview and the apply), reads the file, and applies everything as one undo step labelled with the proposal, refused once stale or while recording. The approval panel shows the load ("Loads the SoundFont preset "Choir Aahs" (bank 0, program 52) from … into Choir"). |
| A2 `search_library {query?, kind?, offset?, limit?}` | The browser's own library search over its roots; kinds `audio`, `soundFont`, `project`, `preset`, `other`; path, kind, size, relative path; paged; says when the index is still being built or truncated. |
| A3 silent warnings | `list_instruments_and_effects`: `needsSource` and `source` on SoundFont player, multisampler, sample player, pad bank, text voice, slice map, slice deck, grain cloud, wave ride (piano keys has its built-in piano and is not listed). `add_channel`: `warning` when the instrument will be silent. `get_project_summary`: `silent` and `needs` per channel and a `warnings` list (same rule as the rack's badge, including empty samplers). `render_and_measure`: `silentChannels` with id, name and reason. |
| A3 how silence is measured | After the main render, each channel that has notes in the rendered region (pattern lanes for a pattern; for the song or a range, pattern clips on unmuted tracks, with patterns repeating inside long clips) and is not muted is rendered alone with the same options; the render stops at its first block with a sample above 1e-6, so a channel that sounds costs little and a silent one costs one render of the region. At most 64 channels per render. With `soloTrackId`, only channels routed to that track. |
| A4 `add_channel {soundFont: {path, bank?, program}}` | One proposal gives a playable channel; same path rule and approval. |
| A5 `list_channel_presets`, `apply_channel_preset {channelId, preset}` | The channel presets of the user's preset library (Windfall has no factory channel presets), applied with the existing `ApplyChannelPreset` command through `dispatch_file_command`, as one undo step labelled with the proposal. |

### In the app

| Item | What |
|---|---|
| B6 (part) | `.sf2` files are `BrowserEntryKind::SoundFont` (own icon). Their menu, and Enter or double-click, open "Add a channel from a SoundFont": the presets, searchable and grouped by family; choosing one adds a SoundFont channel playing it as one undo step (`Session::soundfont_add_channel`). |
| B7 | SoundFont editor: the path text box is gone; **Choose file…** opens the picker with an `.sf2` filter (`backend.pickAudioFile("soundFont")`) and lists the presets; the list is searchable (name, family, GM name, in both languages) and grouped by General MIDI family, with "Drum Kits" and "Other banks". An empty player says it is silent until a SoundFont is chosen. The relink dialog gained the same button. |
| B8 (part) | Settings → **General MIDI SoundFont** (Choose file… / Forget it; only a real SoundFont is kept, `settings.defaultSoundfont`). **Add channel → Add General MIDI instrument…** (rack menu, app Add menu, palette) offers that SoundFont's presets by family and adds the channel as one undo step; with none chosen it says so and opens Settings. No SoundFont is bundled. |
| B9 | The rack marks every channel that needs a source and has none ("no sample", "no SoundFont" for SoundFont players); synths that make their own sound are no longer marked "no sample" (before, every instrument but the subtractive synth was). The mark is a button: on a sampler it opens the file picker, on an instrument the channel's settings with its loader. |

All new strings are in English and Spanish; the three Rust translation
guards and the frontend catalog tests are green.

## 5. Left out

- **B6:** an `.sf2` row does not expand into its presets inside the tree,
  presets cannot be dragged onto the rack or onto an existing SoundFont
  channel, and there is no click-to-preview of a preset. A dialog of the
  file's presets (search, families) is offered from the row instead.
- **B8:** Windfall does not ship channel presets such as "Orchestral /
  French Horn" with tuned release, level and reverb send. General MIDI
  instruments are offered by the sixteen GM families (French Horn is under
  Brass) and load the preset as it is in the user's SoundFont.
- **A5:** only the user's preset library is listed (there are no factory
  channel presets, and the B8 GM presets above were not made).
- The silent-channel measurement checks at most 64 channels per render and
  treats a note as heard if it starts in the region.
- The debug-build window smokes were not rerun (section 3).
- The machine's disk is nearly full (about 10 GB free after the release
  build); the first gate run failed for lack of space. This worktree's
  debug output was deleted; nothing outside it was touched.
