## Per-row result

### `fmt-host-wrapper-options`

Implemented the previously refused Threaded provider in host
`src/threaded.rs`, registered by `src/lib.rs`, and connected it through
`src/{instance,processor,adapter,wrapper}.rs`. Desktop
`src-tauri/src/plugins/{wrapper,runtime}.rs` selects it and acknowledges controls
only after native processing. `src/features/plugins/wrapper-controls.tsx`
enables the existing saved `threaded` choice. Its mounted tests now exercise
selection, undo/redo and an actual document serialization/reopen.

Two prepared audio/event packets circulate through one-entry SPSC queues; one
native job may be outstanding. The measured oracle is a delay of exactly twice
the prepared maximum block, plus existing native/fixed-buffer latency. Timed
events and sidechain PCM travel in the packet; its selected auxiliary input is
captured with the packet rather than read from a later control setting.
Reset/stop on audio only change atomic intent and prepared buffers. The worker
performs native reset/stop. Owner-side deactivation drains/joins outstanding
work and returns the original backend; a refusal recreates its worker while
retaining the pipeline and declared latency. Newer collected controls retire
after older native-policy controls and before next-block outer-queue controls.
Completed packets are not reapplied as pending state.

The callback never waits for a reply, allocates or frees a packet, joins a
thread, calls native lifecycle or wakes an OS primitive. A missing reply at
the next quantum, event capacity exhaustion or native failure latches failure.
The existing effect/instrument fallback and visible health paths then apply.
Offline waits are opted in through `PluginProcessor::set_realtime(false)`.
Windows worker polling uses the existing high-resolution waitable-timer API;
the waiting handle is created/used/destroyed exclusively on the plugin worker.

Source implementation of the exact Still-open item is complete. The existing
processing enum, choice order and `SetPluginWrapper` command are unchanged;
no new persisted field or generated type is needed.

- SOFTWARE: no known remaining implementation of the Threaded selection/provider

  below remain mandatory before this row can be accepted. Shared dynamic
  capabilities, routing and native-platform editor work is listed in its rows.
