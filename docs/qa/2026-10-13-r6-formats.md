## fmt-flp-import

Verified progress after row-one commit `5ebf4f0c`:

- PyFLP/DawVert event 215 offsets now read arpeggiator direction/range/chord,
  time/gate/slide/repeat, full-porta, gate and delay flags; event 83 retains
  pitch range; event 209 reads signed note-echo pan/pitch and feedback/time/count.
  Event 218 reads all optional LFO/tension tails independently of short records.
- Portamento uses DawVert mi_flp.py's `(slide/1024)^4` sixteenth-note steps,
  converted to ms at imported tempo. Range is 0..60,000 ms. Arpeggiator gate
  is raw/48, range 1..4, directions up/down/up-down; time uses the same
  fourth-power step fit with nearest supported rhythmic division. PyFLP reads
  arp time/gate as float32 while DawVert uses u32; that dispute is reported.
  Chord/repeat/slide/random/sticky, unsupported gate and echo flags are named
  individually in reports rather than silently discarded.
- Note echo uses raw feedback/12,800, whole-semitone pitch rounded from cents,
  1..8 repeats and source `time/(2*PPQ)` quarter notes, converted to ms. This
  follows DawVert's /48 step reading at 96 PPQ, while PyFLP documents PPQ
  dependence; source echo pan is reported separately. Stand-in bounds apply.
- Pan, cutoff, resonance and pitch ADSRs map the documented bipolar amount
  /128 to Windfall's target depths (1, 8 octaves, 1, 2,400 cents), with existing
  DawVert timing fit. Predelay/hold/tension/sync are reported separately.
  LFO shape/depth maps at the only publicly documented period anchor
  `speed=32950`, sixteen steps; other period words stay specifically reported.
- Fruity Balance's two-word native state and numbered parameters 0=pan,
  1=volume translate through pan/128 and gain/256. The gain is DawVert's
  approximation; PyFLP calls the source gain logarithmic. Both recorded
  event-223 controls and automation clips use the same functions and the
  existing append-only Balance addresses (`gain=0`, `pan=1`). Original state
  remains in retainedPlugins.
- SimSynth FLP state: public 45-double/76-reserved-byte/flag layout maps
  oscillator shape/coarse/fine/level/on and amplitude ADSR/gain onto TripleOsc.
  Coarse is `(v-.5)*48` semitones, fine `(v-.5)*200` cents, ADSR times `4*v^3`
  seconds, from DawVert's converter. Truncated/nonfinite states use safe
  defaults with a report. Filter/modulation/pulse-width/unison/chorus omissions
  are named; the original blob remains byte-identical after JSON reopen.
  This decoder supplies no lawful evidence for standalone `.syn` files.
- DawVert marker actions plus the public Playlist manual map marker-loop and
  skip to the next source marker, song-loop to imported playlist data end, and
  pause to the existing pause action. A pause following a source song-loop is
  suppressed as the manual documents. No endpoint is invented for unterminated
  regions. Start/punch markers retain names with specific behavior warnings.
  Every successfully imported arrangement marker has a per-item report line.
  Instrument automation without documented source numbering is now reported
  by instrument name and parameter number, with original events retained.
