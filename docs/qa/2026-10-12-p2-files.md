Branch: `gpt/p2-files`. Work is confined to this worktree. All tests in this report are **written, not executed**; the binding brief prohibits worker builds/tests. No generated files are edited.

## File backend and score foundation

All nineteen first-wave native file commands now have typed Backend methods and Tauri callers. Native presets and portable templates report an explicit desktop requirement in the mock; they do not fabricate disk/audio/native state. Plugin database built-ins and annotations use the actual Rust database through a new simulator operation. Scores use the actual Rust capture/load/reader/MIDI writer through the simulator, with a browser memory library.

Added guarded native `score_capture` / `score_apply`; apply takes its checked sample-edit ticket under recording/document locks and prepares off-lock. Reusable scores carry channel-local pattern events with portable channel placeholders, remap them on load, and replace them in the same notes/history batch. MIDI files retain the entire expressive score in a standard marker, alongside interoperable ordinary notes; modified ordinary notes refuse stale metadata. Other MIDI applications may ignore the extension (reported on export).
