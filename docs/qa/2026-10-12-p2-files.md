## File backend and score foundation

All nineteen first-wave native file commands now have typed Backend methods and Tauri callers. Native presets and portable templates report an explicit desktop requirement in the mock; they do not fabricate disk/audio/native state. Plugin database built-ins and annotations use the actual Rust database through a new simulator operation. Scores use the actual Rust capture/load/reader/MIDI writer through the simulator, with a browser memory library.

Added guarded native `score_capture` / `score_apply`; apply takes its checked sample-edit ticket under recording/document locks and prepares off-lock. Reusable scores carry channel-local pattern events with portable channel placeholders, remap them on load, and replace them in the same notes/history batch. MIDI files retain the entire expressive score in a standard marker, alongside interoperable ordinary notes; modified ordinary notes refuse stale metadata. Other MIDI applications may ignore the extension (reported on export).

## Browser and editor workflows

Current-project browser now lists saved controller links with target navigation/removal; patterns/channels/automation entries navigate. The project overview fills the viewport, links pattern/channel cells to their piano roll and clips to playlist selection/reveal, and shows channel relationships under pattern clips.

The plugin catalog exposes native verification status, search, favorites, custom categories and matching preset children. A full-screen picker uses deterministic generated SVG art from name/vendor/kind, persistent user image overrides, search/favorites, double-click and drag payloads. Built-in drops replace a channel's sound or a mixer slot through checked commands. Native hosted drops still use the original add API; that seam is being completed next.

Files browser exposes disk presets and preset library save/apply/delete, and factory/user template list/start/save/delete; File menu/action registry includes these, plus score save/replace/merge. Score controls preserve a lane/selection snapshot and reject delayed dialogs after document changes. Project info exposes all four panning laws and eight project timebases. MIDI export supports the full 1–32767 range with named project-resolution choices. Plugin manager exposes folder removal, blocked rescan, full verify and missing-record removal/status.
