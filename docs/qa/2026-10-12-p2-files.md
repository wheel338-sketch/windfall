## Implementation joins

`ProjectFilesBackend` and Tauri callers expose all nineteen first-wave native file commands, plus guarded score capture/apply, plugin-preset apply and hosted plugin insertion/replacement. Native discovery and preparation run off-lock; generation/revision checks and the sample-edit ticket admit a single history operation under recording/document guards. Hosted channel replacement retains routing/name/color. Tauri wrappers remain thin and commands are appended to the handler.

The browser memory backend uses actual Rust preset and score semantics through WebAssembly, not a fabricated document. Built-in catalog and annotations use the Rust plugin database. Portable templates, audio preset assets and opaque native state explicitly refuse in the mock. Files panel loads template and preset capabilities independently so a native-only template error cannot hide usable memory presets.

Browser Plugins/Files tabs, File/Add/View action registry entries, full-screen overlays, existing Base UI/shadcn controls and channel/mixer drop seams form the frontend path. The picker contains its own destination dock because the modal prevents access to underlying rack/mixer targets. Catalog control IDs are instance-local; the manager's embedded catalog honors its requested mixer track. Plugin preset application chooses an instrument or effect destination from the saved preset role, so an old mixer selection cannot steal an instrument load. Memory preset reviews include their file path and resource-free library saves replace the native safe filename.

Score MIDI metadata is a standard marker (`windfall.score.v1:` JSON), not a proprietary binary format. Ordinary MIDI notes remain interoperable; other applications may ignore the expressive extension, reported on export. Reading requires those ordinary notes to match the metadata. Native score export writes 960 PPQ. Arbitrary callers that rewrite such a score song at a different PPQ may quantize the ordinary notes and trigger that intentional refusal; ordinary project MIDI export supports every 1–32767 PPQ.

`PanLawRamp` interpolates frame-addressed gains without allocation or locks and preserves interrupted-ramp continuity. Channel/mixer/clip changes use the existing five-millisecond glide. Subtractive voices advance the ramp on the oversampled clock; granular voices use output frames and retain their historical equal-power center level. Native in-process controls map project stereo gains to note balance plus an independent Volume expression. Capability-dependent semantics and event pressure need native verification; that path does not establish isolated bridge support.

Extraction GC deletes only registered direct own-session `projects/project-*` roots after replacement/save. It preserves current sample roots, saved-path roots, actual document/history sample sources, preset-capture pins and archive leases. Collection happens off document/audio guards, serializes with save/copy, uses a nonblocking save guard to avoid held-save replacement deadlocks and retries when archive leases drop. It refuses untracked roots and symlinks. Durable release/cross-session collection remains explicitly incomplete.

Publication hooks terminate actual child test executables with exit 73 without destructors. Visible final projects, copied samples and archives must be complete or absent. Older/competing paths and source bytes remain unchanged. Failed-process staging may remain until the parent temp fixture is dropped; it is never interpreted as a project. Cancellation after committed archive publication reports success.
